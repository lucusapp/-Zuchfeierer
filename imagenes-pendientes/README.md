# Imágenes pendientes de integrar

Suelta aquí (arrastrando desde el explorador de archivos de tu ordenador, o con
"Reveal in Finder/Explorer" + copiar-pegar) las fotos y esquemas reales del
manual que quieras que integre en la app.

No hace falta que las nombres de forma especial: dime en el chat qué archivo
corresponde a qué parte del manual (o a qué sección de la app) y yo la muevo a
`public/content-images/...` con el nombre y sitio correctos, y actualizo el
Markdown para que la referencie.

Esta carpeta es solo un buzón de entrada — se puede borrar su contenido una
vez integrado.
