## Numeración

El sistema establece como coche nº 1 el que tiene la cabina habilitada, y numera correlativamente el resto en orden ascendente desde ahí.

**Trayectos especiales**: 001 = pruebas, 002 = sin servicio.

## Anuncio de estación

- El texto **TT11** se muestra cuando el tren se acerca a la estación que va a anunciar.
- Pulsando **"A: ANULA"** se anula el siguiente anuncio.

## Error de distancia

- Si antes de llegar a la distancia esperada se produce apertura y cierre de puertas, aparece el texto **TT12** (error en la medida de la distancia).
- Si ocurre entre dos estaciones: pulsar **"A"** para anular el anunciador.
- Si ocurre estando en una estación: pulsar **"B"** para seleccionar la próxima parada.

## Control de megafonía

- Teclas: **TR, MU, TA, CA, PU, AC**. La última línea del display indica el modo de funcionamiento.
- **TR** (Habla-Escucha): activo en todos los terminales, sin actividad predefinida.

## Conexión cabina-cabina

- Se activa con el pulsador **CA** en cualquiera de las cabinas. El mensaje sale por los altavoces monitores de todas las cabinas; el display muestra "CAB -- CAB".
- Solo puede finalizarla el terminal que la solicitó, o un intercomunicador.

## Conexión cabina-público

- Se activa con el pulsador **PU**; el display muestra "CAB PUB".
- Puede interrumpirla un intercomunicador o la conexión cabina-cabina.
